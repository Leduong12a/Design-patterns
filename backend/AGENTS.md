### Architecture Analysis Skill

- Analyze the source code structure based on Clean Architecture (Domain, Application, Infrastructure, and Presentation layers).
- Identify business modules, application workflows, and dependencies between components.
- Understand and explain Entities, Use Cases, Repositories, Services, and Controllers.
- Trace data flow from HTTP requests through Use Cases to repositories, external services, and databases.
- Evaluate adherence to Domain-Driven Design (DDD), SOLID principles, and Ports & Adapters architecture.
- Assist with codebase exploration, architecture reviews, system documentation, and improvement recommendations.

### Code Review Agent

- Analyze code for bugs, logic errors, and security vulnerabilities.
- Enforce coding standards, best practices, and project-specific guidelines.
- Suggest improvements for performance, maintainability, and readability.
- Detect anti-patterns and code smells.
- Verify adherence to SOLID principles and clean architecture.
- Check for potential race conditions, memory leaks, and other runtime issues.

### TypeScript Skill

- Compile and type-check TypeScript code for syntax errors and type mismatches.
- Use TypeScript features like generics, interfaces, and type aliases correctly.
- Refactor JavaScript code to TypeScript, adding proper type annotations and interfaces.
- Analyze and fix type-related errors in existing TypeScript code.
- Convert between TypeScript versions or transform code to newer TypeScript features.
- Provide type safety explanations and guide on how to design type systems for applications.
